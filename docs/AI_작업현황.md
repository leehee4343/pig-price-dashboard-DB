작성일: 2026-08-21. Claude Code 세션 토큰 소진으로 이어서 작업할 도구(Gemini 등)를 위해 정리한 문서입니다. 이 파일은 git에 커밋하지 않은 로컬 전용 메모입니다.

## 프로젝트 개요

- `index.html` 단일 파일 정적 대시보드 (프레임워크 없음, Chart.js v4.4.1 인라인 번들, SheetJS `xlsx` CDN)
- `update-data.js` — 관리자 PC에서 원본 엑셀 2개(`돼지 거래가격정보(...).xlsx`, `업체정보(...).xlsx`)를 읽어 통계를 집계하고, 그 결과를 `index.html` 안의 `<script id="DATA_HOLDER">`/`RAW_PRICE_HOLDER`/`RAW_COMPANY_HOLDER` 3개 태그에 주입하는 Node 빌드 스크립트 (`npm run update`)
- GitHub 저장소: `leehee4343/pig-price-dashboard` (Public, 팀 공유용으로 유지하기로 사용자가 확정), GitHub Pages 배포: `https://leehee4343.github.io/pig-price-dashboard/`

**핵심 아키텍처 원칙 (반드시 지켜야 함):** `index.html`의 `processDashboardData()`(브라우저에서 필터 적용 후 재집계)와 `update-data.js`의 집계 로직은 거의 동일하게 복제되어 있습니다. 집계 규칙을 바꿀 때는 **반드시 두 파일 모두** 수정해야 하며, 안 그러면 "빌드 시 기본 화면"과 "필터를 바꿨을 때 재계산되는 화면"의 숫자가 서서히 어긋납니다.

## 아직 처리 안 된 것 (다음 작업자가 참고)

1. **GitHub 토큰 폐기** — 과거 커밋 히스토리(`fbf43dd` 이전)에 XOR로 약하게 난독화된 GitHub Personal Access Token이 남아있습니다. 이미 복호화해서 사용자에게 알려드렸고, 사용자가 https://github.com/settings/tokens 에서 직접 폐기해야 합니다 (API로 대신 폐기 불가). 폐기 여부는 미확인 상태입니다.

3. **히스토리 완전 삭제(`git filter-repo` 등)는 미실행** — 사용자가 "일단 최신 커밋에서만 제거"를 선택했고, 과거 히스토리 전체 삭제(force-push 필요)는 다음에 필요하면 진행하기로 함.
